【代码使用】

  所有 .cpp 文件通过文件顶部 #define 宏修改参数，编译即用：
    g++ -std=c++11 Code/文件名.cpp -o output/输出名 && ./output/输出名
  Python 需先安装依赖：
    pip install -r requirements.txt
